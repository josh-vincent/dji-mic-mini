# Artwork

The original MicTrigger app icon and DMG background were generated with OpenAI's built-in image generation tool, then converted into macOS bundle and installer formats by the build scripts.

- `AppIcon.png`: a premium graphite-and-cyan macOS icon combining a compact wireless microphone transmitter with a shortcut-trigger motif. It intentionally contains no text or third-party branding.
- `DMGBackground.png`: a restrained graphite-and-midnight signal-wave background with open areas for the app and Applications icons. It intentionally contains no text or third-party branding.

Run `scripts/generate-icons.sh` to create `AppIcon.icns`, or `scripts/create-dmg.sh` to build the complete drag-to-Applications disk image.
